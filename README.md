# diprotodon

This project is now **[steller](https://github.com/scadoshi/steller)**.

A minimal Redis-compatible in-memory key-value server in Rust, hand-written from the wire protocol up. Same code, same history, new name.

Renamed because Steller's jay mimics red-tailed hawks well enough to clear a feeder, which is roughly what this does to `redis-cli`. It pairs with [chickadee](https://github.com/scadoshi/chickadee), the sibling LSM storage engine.

Nothing is developed here. Go to [scadoshi/steller](https://github.com/scadoshi/steller).
